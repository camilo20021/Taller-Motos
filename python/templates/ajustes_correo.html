Ajustes de correo

Para que los clientes reciban el aviso de "moto ingresada" y "moto lista".

{{ 'Correo configurado' if taller.correo_configurado else 'Correo sin configurar' }}

Los correos se envían a través de Brevo (antes Sendinblue), un servicio gratuito para esto (300 correos/día gratis, sin tarjeta). No requiere "contraseña de aplicación" de Gmail, que Google restringe cada vez más.

Pasos: crea una cuenta gratis en brevo.com → en el panel ve a SMTP & API → API Keys y genera una → pégala abajo. Después ve a Senders & IP → Senders y verifica el correo que vas a usar como remitente (Brevo te manda un enlace de confirmación) — sin verificarlo, el envío falla.

La primera vez que envíes, Brevo puede rechazarlo con un error de "IP no reconocida" — es normal, es una protección de seguridad de tu cuenta nueva. Entra a app.brevo.com/security/authorised_ips (o Ajustes → Seguridad en tu panel de Brevo) y desactiva la opción de "autorización de IP", o agrega la IP que te indique el mensaje de error. Después de eso, el envío funciona normal.
